# Sufganiya Rating Night 🍩

Live Hanukkah sufganiya voting.

- **Voting (phones):** https://myshell-bit.github.io/sufganiya-night/
- **Big screen:** https://myshell-bit.github.io/sufganiya-night/#screen

Votes go to a Google Form; the big screen reads the form's response sheet (published as CSV) every 5 seconds.
Settings live at the top of the script in `index.html`: `FORM_ACTION`, `ENTRY`, `CSV_URL`, `PAY_URL`.

To start a fresh round, delete the response rows in the Google Sheet.
